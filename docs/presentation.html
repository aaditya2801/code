Domain: Social Media Analytics | Platform: Local PySpark

1. Project Context

  • Brands monitor social media to understand customer perception and reputation.
  • Twitter posts provide real-time feedback on service quality and complaints.
  • Dataset: Twitter US Airline Sentiment (Feb 2015, CrowdFlower/Kaggle).
  • Each record: post text, sentiment, brand, retweets, complaint reason.
Goal: Transform raw social data into actionable business insights using a lakehouse pipeline.

2. Objectives

  • Bronze: Ingest raw social media data without transformation.
  • Silver: Clean data — nulls, duplicates, schema correction.
  • Gold: Build business tables for sentiment, complaints, activity.
  • Insights: Identify brand health, pain points, and peak activity.

4. Bronze Layer — Raw Ingestion

Load CSV into PySpark and save as Parquet without any cleaning.

df = spark.read.option("header", True).csv("data/bronze/social_media_tweets_raw.csv") print("Row count:", df.count()) # 14,640 df.write.mode("overwrite").parquet("data/bronze/tweets_bronze")
Preserves original source for audit and reprocessing.

5. Silver Layer — Data Cleaning

Cleaning Steps

  • Rename columns (airline → brand)
  • Cast types, parse timestamps
  • Filter invalid sentiment values
  • Remove duplicates by post_id
  • Fill selected null values
155 rows removed | 14,485 clean rows
silver = bronze.select( F.col("tweet_id").alias("post_id"), F.lower(F.trim(F.col("airline_sentiment"))).alias("sentiment"), F.col("airline").alias("brand"), ) silver = silver.dropDuplicates(["post_id"])

6. Gold Layer — Business Tables

  • fact_posts — clean post-level data
  • brand_scoreboard — % negative / positive by brand
  • top_negative_reasons — complaint categories
  • activity_by_day / hour — when conversations peak
  • top_engagement_posts — most retweeted posts
brand_scoreboard = brand_totals.join(brand_neg, "brand", "left") .withColumn("negative_pct", F.round(100 * F.col("negative_posts") / F.col("total_posts"), 2)) .orderBy(F.desc("negative_pct"))
