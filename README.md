# Big Data Analytics Capstone — Social Media Sentiment (Local PySpark)

**Path B:** PySpark Lakehouse (Bronze → Silver → Gold)  
**Platform:** Local laptop (no cloud required)  
**Domain:** Social Media analytics  

## Project title
**Social Media Brand Sentiment & Engagement Analytics** using Twitter US Airline Sentiment data (public social posts about major brands).

## Dataset
| Item | Detail |
|------|--------|
| Source | Twitter US Airline Sentiment (CrowdFlower / Kaggle mirror) |
| File | `data/bronze/social_media_tweets_raw.csv` |
| Size | **14,640 rows**, **15 columns** (meets ≥5,000 × ≥5) |
| Why social media? | Real public posts, sentiment labels, engagement (`retweet_count`), brands, complaint reasons |

## Architecture

```
Raw CSV (social posts)
        ↓
 data/bronze/tweets_bronze     ← as-is ingestion
        ↓  PySpark cleaning
 data/silver/tweets_silver     ← nulls, dups, types fixed
        ↓  PySpark aggregations
 data/gold/*.parquet + *.csv   ← business tables
        ↓
 docs/charts/*.png             ← insights for report & demo
```

## Setup (Windows)

### 1) Prerequisites
- Python 3.10+ (tested with 3.13 + PySpark 4.2)
- Java 11+ (`java -version` should work)
- Windows: `tools/hadoop/bin/winutils.exe` is included (needed for Spark file writes)

### 2) Install packages
```bash
cd big-data-social-media-capstone
pip install -r requirements.txt
```

### 3) Run full pipeline
```bash
python scripts/run_all.py
```
On Windows PowerShell (optional explicit Hadoop home):
```powershell
$env:HADOOP_HOME = (Resolve-Path tools\hadoop).Path
python scripts/run_all.py
```

Or step by step:
```bash
python scripts/01_bronze_ingest.py
python scripts/02_silver_clean.py
python scripts/03_gold_transform.py
python scripts/04_insights_charts.py
```

## What each layer does

### Bronze
- Load raw social media CSV with PySpark  
- Save Parquet snapshot **without cleaning**

### Silver
- Rename columns for analytics (`airline` → `brand`, etc.)  
- Cast types, parse timestamps  
- Remove null/invalid posts, deduplicate by `post_id`  
- Normalize sentiment labels  

### Gold (business tables)
| Table | Purpose |
|-------|---------|
| `fact_posts` | Clean post-level fact table |
| `sentiment_by_brand` | Sentiment counts per brand |
| `brand_scoreboard` | % positive / negative by brand |
| `top_negative_reasons` | Top social complaint reasons |
| `top_engagement_posts` | Most retweeted posts |
| `activity_by_day` / `activity_by_hour` | When conversations peak |
| `daily_sentiment_trend` | Sentiment over time |

## Sample insights (generated by pipeline)
1. Which brands have the **worst / best** social sentiment  
2. Top **customer pain points** from negative posts  
3. **Peak weekdays and hours** for social conversation volume  
4. Engagement leaders (high retweets)
